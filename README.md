# 🧮 Calculadora Tudo-em-Um

Calculadora web completa em um **único arquivo HTML** — sem instalação, sem dependências, sem build. Abre no navegador e funciona até offline.

## ✨ Funcionalidades

- **Básica** — quatro operações, parênteses, porcentagem, memória (M+/M−/MR/MC), histórico
- **Científica** — trigonometria direta e inversa, log, ln, raiz, potência, fatorial, π, e, alternância graus/radianos
- **Programador** — HEX/DEC/OCT/BIN em tempo real, operações bit a bit (AND, OR, XOR, NOT, deslocamentos), 32 bits sem sinal
- **Função** — avalia f(x) em um ponto, gera gráfico e tabela de valores estilo caderno (mostra a substituição passo a passo, ex: `f(-1) = (-1)²-4(-1) = 5`); aba dedicada para **função quadrática** (Δ, raízes, vértice, concavidade, gráfico da parábola)
- **Física** — fórmulas de Cinemática, Dinâmica, Energia, Eletricidade, Termologia e Ondas
- **Conversor** — comprimento, massa, temperatura, volume, velocidade e tempo
- **Estatística** — média, mediana, moda, variância e desvio padrão (populacional e amostral)
- **Geometria** — área e perímetro de quadrado, retângulo, triângulo, círculo, trapézio, paralelogramo e losango

## 🚀 Como usar

Baixe o repositório e abra o `index.html` em qualquer navegador. Não precisa de servidor, internet ou instalação de nada.

### Hospedar com GitHub Pages (opcional, pra acessar de qualquer lugar)

1. No repositório, vá em **Settings → Pages**
2. Em "Source", selecione a branch `main` e a pasta `/root` (raiz)
3. Salve — em alguns minutos o app fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`

## 🛠️ Tecnologia

HTML, CSS e JavaScript puro — sem frameworks, sem dependências externas, sem etapa de build. Todo o parser de expressões matemáticas e a lógica de cada modo foram escritos do zero.
